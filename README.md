# KotlinHotel



**Мобильное приложение отеля на Android** — бронирование номеров, услуги, отзывы и электронный ключ в одном приложении.

[Kotlin](https://kotlinlang.org)
[Android](https://developer.android.com)
[Hilt](https://dagger.dev/hilt/)
[Room](https://developer.android.com/training/data-storage/room)



---

## О проекте

**KotlinHotel** — демонстрационное Android-приложение для гостиницы «Grand Hotel». Оно показывает, как собрать полноценное приложение с каталогом номеров, бронированием, услугами (ресторан, SPA, экскурсии, трансфер), отзывами и электронным ключом по NFC.

Подходит как **образец архитектуры**, **портфолио-проект** или **стартовая заготовка** для реального отельного приложения.

---

## Возможности


| Раздел            | Описание                                                                                             |
| ----------------- | ---------------------------------------------------------------------------------------------------- |
| **Главная**       | Приветствие, быстрые действия, рекомендации по номерам                                               |
| **Номера**        | Каталог номеров, детали, удобства, бронирование с датами заезда/выезда                               |
| **Услуги**        | Ресторан (меню, заказ в номер), SPA (расписание, запись), экскурсии, трансфер (расписание автобусов) |
| **Оплата**        | Оплата услуг картой или наличными (демо)                                                             |
| **Отзывы**        | Список отзывов, средний рейтинг, написание отзыва                                                    |
| **Инфо об отеле** | Карта отеля, контакты, события                                                                       |
| **Ключ**          | Электронный ключ номера по NFC (открытие двери симуляция)                                            |

## Технологии

- **Язык:** Kotlin 2.1  
- **UI:** ViewBinding, Material Design, ViewPager2, RecyclerView  
- **Навигация:** Navigation Component (Single Activity, граф фрагментов)  
- **Архитектура:** разделение на domain / data / presentation, MVVM  
- **DI:** Hilt (Dagger)  
- **Локальные данные:** Room  
- **Асинхронность:** Kotlin Coroutines  
- **Демо-данные:** kotlin-faker  
- **Минимальная версия Android:** 24 | **Целевая:** 36

## Архитектура

```
app/
├── data/           # Реализации репозиториев, генерация mock-данных
├── di/             # Модули Hilt (AppModule)
├── domain/         # Модели (Room, Booking, Review, HotelService, Event, User), интерфейсы репозиториев
└── presentation/   # UI: фрагменты, ViewModel, адаптеры
    ├── home/
    ├── rooms/      # список, деталь, форма бронирования
    ├── services/   # ресторан, SPA, экскурсии, трансфер
    ├── payment/
    ├── reviews/
    ├── key/        # NFC-ключ
    └── hotelinfo/  # карта, контакты, события
```

Данные пока от **mock-репозиториев** (без бэкенда). При необходимости их можно заменить на API или другой источник.

## Требования

- **Android Studio** (рекомендуется Ladybug / Koala или новее)

- **Устройство или эмулятор** с Android 7.0 (API 24) и выше

## Установка и запуск

1. **Клонировать репозиторий**
  ```bash
   git clone https://github.com/your-username/KotlinHotel.git
   cd KotlinHotel
  ```
2. **Открыть в Android Studio**
  File → Open → выбрать папку `KotlinHotel`.
3. **Синхронизировать Gradle**
  Дождаться окончания синхронизации (и при необходимости загрузки зависимостей).
4. **Запустить приложение**
  Подключить устройство или запустить эмулятор → Run (▶️) или `./gradlew installDebug`.
   Для установки из командной строки:

После запуска откроется главный экран с нижней навигацией: **Home**, **Rooms**, **Services**, **Info**, **Reviews**. Электронный ключ доступен с главного экрана (для NFC нужно реальное устройство).

## Настройка (для разработчиков)

- **Пакет приложения:** `com.example.kotlinhotel` — при необходимости сменить в `build.gradle.kts` (applicationId) и в коде.  
- **Имя отеля и тексты:** `app/src/main/res/values/strings.xml`.  
- **Тема и цвета:** `res/values/themes.xml`, `colors.xml`.  
- **Подключение API:** заменить реализации в `data/` на репозитории, работающие с вашим бэкендом, и при необходимости добавить сетевой слой (например, Retrofit) и модуль в Hilt.

## Для контрибьюторов

- Ветка по умолчанию для разработки — `main`.  
- Перед коммитом желательно запускать тесты:  
`./gradlew test` (unit), при наличии — инструментальные тесты на устройстве/эмуляторе.  
- Форматирование кода — в стиле Kotlin standard (например, как настроено в проекте / в вашей команде).  
- Изменения в API (например, репозиториев) лучше согласовывать через issue или обсуждение.

---

## Почему этот проект полезен

- **Актуальный стек:** Kotlin, Hilt, Navigation, Room, ViewBinding — набор для современного Android.  
- **Целый сценарий:** от каталога и бронирования до оплаты и «ключа» — удобно смотреть поток целиком.  
- **Чёткое разделение слоёв:** domain не зависит от Android, данные подменяемы (mock → API).  
- **Готовый каркас:** можно взять за основу и доработать под свой отель или другой hospitality-сервис.
